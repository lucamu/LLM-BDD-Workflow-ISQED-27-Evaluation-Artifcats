## Contents

**README.md**: This README  

**result.json**: JSON object containing all evaluation information retreived from our evaluation with Xelium/JasperGold  
**spec.feature**: Gherkin specification generated by our workflow to serve as the basis for RTL/SVA generation  

**rtl_eval/README.md**: Overview of RTL evaluation artifacts and results  
**rtl_eval/.../dut.v**: RTL implementation generated by the workflow/baseline  

**sva_eval/README.md**: Overview of SVA evaluation artifacts and results  
**sva_eval/../dut.v**: Reference RTL used for signal extraction and scoring on the SVA path  
**sva_eval/.../sva.sv**: Set of SVAs generated by the workflow/baseline  
**sva_eval/.../module/module.f**: File include list for JasperGold evaluation  
**sva_eval/.../module/module.prove.tcl**: TCL script used for JasperGold evaluation  
**sva_eval/.../module/module.sv**: Top-level module, same as sva_eval/.../dut.v  
**sva_eval/.../module/module_\*.v**: Submodules to be included for JasperGold evaluation
